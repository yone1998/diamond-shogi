# ダイヤモンド将棋

本将棋の駒性質を維持しつつ、盤面を77マスの菱形格子にした変則将棋です。2人対戦と CPU 対戦に対応しています。

**プレイ:** https://yone1998.github.io/diamond-shogi/

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで表示された URL（通常 `http://localhost:5173`）を開いてください。アプリ内の「ルール」からも説明を読めます。

```bash
npm test
```

### GitHub Pages

公開 URL: **https://yone1998.github.io/diamond-shogi/**

`main` への push で GitHub Actions が自動ビルド・デプロイします（`.github/workflows/deploy-pages.yml`）。

ローカル確認:

```bash
npm run build
npm run preview
```

## ルール概要

### 盤

- 17筋 × 9段。存在するマスは `file % 2 === rank % 2` のみ（合計 **77**）。
- 各段のマス数: 9, 8, 9, 8, 9, 8, 9, 8, 9。
- 本将棋の「1段前」＝ダイヤモンド将棋の「2段前」（同筋 `(0, ±2)`）。
- 同じ段方向 `(±2, 0)`、辺方向 `(±1, ±1)`。

### 初期配置

- 先手・後手は180度回転対称。合計40枚。
- 後手: 1段目に香桂銀金王金銀桂香、**4二飛・14二角**、3段目に奇数筋の歩9枚。
- 先手: 7段目に奇数筋の歩9枚、**4八角・14八飛**、9段目に香桂銀金王金銀桂香。

### 駒・禁手・勝敗

- 王・金・銀・桂・香・飛・角・歩および成駒の動きは、本将棋を菱形座標へ写像したもの。
- 成り・持ち駒・二歩・打ち歩詰め・行き所なし・王手詰み等は本将棋に準拠。
- **行き所なし（幾何）**: 歩・香は先手1〜2段／後手8〜9段、桂は先手1〜3段／後手7〜9段。
- 二歩により、自歩が全奇数筋にある初期局面では、打てる歩は偶数筋側に限られる（仕様）。
- 棋譜は本将棋と同様、直前に進んだマスを取る手は **「同」**（例: ▲同歩）。

## 確定仕様・必須条件（開発時の前提）

以下はユーザー指示により確定した仕様・必須条件です。勝手に変更・補完しないこと。

### 盤面・座標

- 17筋 × 9段。存在するマスは `file % 2 === rank % 2` のみ（合計 **77**）。
- CSS で盤を45度回転する実装は不可。77個の菱形セルを独立に敷く。
- **盤の座標表示位置はレイアウト変化で動かさないこと（必須）**。勝敗バナーはオーバーレイとし、持ち駒枠と Y が重なってよい（盤の縮尺を圧迫しない）。

### UI・操作（必須）

- アプリ名は **ダイヤモンド将棋**。アイコンはダイヤモンド。
- 盤は菱形を**縦長**に。駒は**マスからはみ出さない**こと（必須）。駒種でサイズ差あり。
- 候補マスは塗りつぶしではなく**薄暗い丸**（取りは少し濃い丸＋輪郭）。直前手は寒色の薄め。
- **選択中マスは緑塗りではなく暗幕**。盤外の暖かい茶・緑と区別できる冷たい暗色にすること。
- マス内の座標文字は出さない（外周の筋・段番号のみ）。
- 駒クリックで**実際の移動可能マスをハイライト**（線のみ表示は不可）。
- 先手視点: **右が1筋・左が17筋、上が一段・下が九段**。
- CPU後手時は盤を **180度反転**（手前＝自陣）。持ち駒は下＝ユーザー、上＝CPU。
- 棋譜座標は盤面ラベルと同じ絶対座標（筋は `displayFile`）。
- **持ち駒枠の横幅・高さは固定（必須）**。枚数表示が見切れないこと。
- 持ち駒／盤上駒の選択中に、候補外・盤外・持ち駒枠の空きをクリックしたら選択解除。
- 棋譜・手数をリアルタイム表示。直前手の移動元・先を色付け。直前到着マスへの取りは「同」。
- 「待った」あり。投了後は勝敗表示＋対局設定画面（設定外クリックで盤面確認可）。
- 対局モード: **2人対戦** / **CPUと対局**。CPU強さ3段階（弱い／普通／強い）。
- CPU対戦の手番デフォルトは **ランダム**。表示順は **ランダム → 先手 → 後手**。
- 対局設定ダイアログはモード切替でもサイズ固定。

### 評価・CPU

- 初期局面の静的駒割り・配置点は対称で0。手番ボーナスのみ非ゼロ。
- 探索用評価に手番補正を含め、表示用の局面評価は手番なしで0を維持してよい。

## CPU の強さ（アルゴリズム差）

| レベル | 探索の深さ | 候補手数 | 乱数 | 制限時間 | 内容 |
|--------|------------|----------|------|----------|------|
| **弱い** | 1（自分の手だけ） | ルート最大16 | 大 | — | 駒得中心の即評価＋ばらつき |
| **普通** | 2（自分→相手） | 36 / 応手24 | 中 | — | 相手の最善応手を仮定した1手読み |
| **強い** | 4＋αβ＋王手延長＋静止探索 | 最大120→有望手に集中 | なし | **12秒上限**（CPU思考中のみカウント） | 反復深化。詰み・王手を優先して深く読む |
